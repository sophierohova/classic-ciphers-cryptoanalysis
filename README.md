# Реализация и криптоанализ классических шифров подстановки

Консольное приложение на C++ для исследования алгоритмов моноалфавитной и полиалфавитной подстановки, а также автоматизированного криптоанализа.

**Шифрование и дешифрование:** Алгоритмы Цезаря и Виженера для кириллического и латинского алфавитов.

**Ввод/вывод:** Поддержка интерактивного ввода через консоль и потоковой работы с файлами в кодировке UTF-8.

**Криптоанализ:** 
  Атака полным перебором для шифра Цезаря.
  Автоматический подбор ключа на основе частотного анализа.

## Специфика реализации
В кодовых таблицах кириллическая буква `Ё` (0x0401) вынесена за пределы `А-Я` (0x0410–0x042F). Для сохранения линейности сдвигов реализованы:
1. **get_pos(c):** Преобразует символы в виртуальные индексы кольца вычетов \(\mathbb{Z}_{33}\), где `Ё` фиксируется на 6 месте.
2. **get_char_from_pos(pos):** Восстанавливает код Юникода на основе виртуального индекса.
3. **norm_key(key):** Приводит любые ключи к диапазону алфавита по формуле `((key % size) + size) % size` для симметрии дешифрования.

## Криптоанализ и оценка стойкости
**Шифр Цезаря** обладает нулевой стойкостью. Размер ключа ограничен мощностью алфавита (33). Полностью компрометируется полным перебором или частотным анализом, так как моноалфавитная подстановка не скрывает частотность символов исходного языка.
**Шифр Виженера** устойчив к простому частотному анализу из-за полиалфавитного размытия частот. Мощность ключа растет экспоненциально длине пароля. При коротких ключах уязвим к методу Касиски.

## Пример
1. Шифрование текста со сдвигом "5":

Ввод: `Около окна одиноко стоял огромный старый тополь.`

Вывод: `Йёйжй йёиы йядийёй мнйъж йюлйзице мнылце нйкйжч.`

2. Запуск частотного криптоанализа:

Ввод: `Йёйжй йёиы йядийёй мнйъж йюлйзице мнылце нйкйжч.`

Анализ: Автоматически вычислен вероятный сдвиг дешифрования "28"

Вывод системы: `Около окна одиноко стоял огромный старый тополь.`
